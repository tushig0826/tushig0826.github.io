Thesis

BME bachelor thesis

Out-of-Distribution Detection in Image Captioning based on Deep Learning

Large captioning models sometimes describe things that are not in the image. I implemented ReCap (Refining Captions for Foundation Model-Based Image Captioning), which rejects out-of-distribution captions and replaces them with better alternatives.

Select a stage to see what I built.

The problem

Large foundation-model captioners can write captions that do not match what is in the image. These out-of-distribution (OOD) captions look fluent, so they are hard to spot.

The idea

Softmax probability only reflects how the model ranks its own words. A CLIP similarity score compares the caption with the image directly, so it can flag a caption that does not belong.

What I delivered

An OOD benchmark built with Stable Diffusion-based models, large captioners integrated into the pipeline, a CLIP-based scoring solution, and the ReCap reject-and-replace algorithm.
